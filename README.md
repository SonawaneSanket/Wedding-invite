# Wedding Invitation Web App

A luxury, interactive wedding invitation website built with HTML5, CSS3, and JavaScript.

## Features
- **Cinematic Gate Reveal & Preloader:** Elegant opening sequence with animated royal gates and monogram.
- **Heart Scratch Card:** Interactive canvas-based scratch card to reveal the "Save the Date".
- **Interactive Confetti & Sparkles:** Celebration gold and maroon foil particle bursts.
- **Background Music Player:** Romantic soundtrack with smooth fade-in and mute/play toggle.
- **Live Countdown Timer:** Dynamic countdown to the wedding ceremony.
- **Event Itinerary & Timeline:** Detailed schedules for Haldi, Mehendi, Sangeet, and the Wedding Ceremony.
- **RSVP & Blessings:** Interactive RSVP form and guest blessings section.
- **Fully Responsive & Accessible:** Optimized for mobile, tablet, and desktop viewports, with reduced-motion support.

## How to Run Locally

### Option 1: Using Node / npx (Recommended)
```powershell
npx serve .
```
Then open `http://localhost:3000` in your browser.

### Option 2: Using Python
```powershell
py -m http.server 8000
```
Then visit `http://localhost:8000`.

### Option 3: Direct File Open
Simply double-click `index.html` or open it with your preferred browser.
